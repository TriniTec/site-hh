# Histórico de textos do site

Toda mudança de texto entra aqui. Texto já revisado pelo Filipe só muda com pedido ou aprovação dele
(antes e depois mostrados primeiro).

Cada trecho tem a lista das versões, da mais antiga para a mais nova, **sempre com o texto inteiro**.
A coluna "O que mudou" só ajuda a achar a diferença. A última linha de cada tabela é o texto no ar.
Nos cartões, `/` separa os parágrafos e a frase em **negrito** é a linha de destaque.
