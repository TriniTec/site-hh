# Links públicos de WhatsApp

Gerado por scripts/build.mjs a partir de site.config.json. Não editar à mão: mude o arquivo de configuração.

Regra: fora do site e no próprio site, use sempre estes endereços, nunca o link wa.me direto. Trocar o número em
site.config.json atualiza todos de uma vez. Cada acesso é contado no Umami como evento "whatsapp-<origem>".
A mensagem não diz de onde a pessoa veio; o sinal é uma palavra-chave discreta que só o Filipe conhece.
